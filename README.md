# Scribbler1120 – Adorf entdecken (Godot)

Jump & Run mit dem Schreiberling durch das heutige Adorf, gezeichnet im Scribbler1120-Stil.
Die Welt wird Ortsteil für Ortsteil aus Kartendaten aufgebaut.

## Spielen
Neueste Version im Browser (auch am Handy): https://jcmeier86-droid.github.io/scribbler1120-spiel/

Windows-Version zum Herunterladen: unter „Actions“ den neuesten Lauf öffnen → „Scribbler1120-Windows“.

## Lokal starten
1. Godot 4.7.2 (Standardversion ohne .NET) von godotengine.org laden.
2. Godot öffnen → „Importieren“ → diesen Ordner wählen → Abspielen (F5).

Steuerung: WASD/Pfeile laufen · Leertaste springen · Enter/F Geschichte lesen · Q/E oder rechte Maustaste Kamera drehen · Gamepad geht auch.

## Stand (Meilenstein 1 – Grundgerüst)
- Dorfmitte mit Gelände (Talkessel an Rhene und Bicke), Straßen mit Gehwegen, ~75 Gebäuden als 3D-Körper, Kirche als romanische Basilika mit Turm und Apsis
- Tusche-Shader: Konturen, Farbstufen, Schraffur, Papierwirkung
- Schreiberling als Platzhalter (Rückansicht aus dem Charakterbogen), 5 Stationen mit Geschichten, Federn zum Sammeln
- Werkzeug für echte OpenStreetMap-Exporte, automatische Übernahme von 3D-Figur und gezeichneten Fassaden
