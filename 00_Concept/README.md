# Konzept
- `Styleguide/masterprompt_spielwelt.md` – verbindlicher Bildstil: reale Gegenwart, gezeichnet im Scribbler1120-Stil.
- Referenzen: Luftbilder der Ortsmitte (Alamy-Stockfotos) dienen nur als Vorlage für Anordnung, Dachfarben und Formen. Sie dürfen ohne Lizenz nicht ins Spiel oder ins Repo.
